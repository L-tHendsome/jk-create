# Jk's 3D Farm — каталог 3D-печатных наборов

Сайт: https://l-thendsome.github.io/jk-create/

Это статическая копия сайта на WordPress-теме jk-create (бренд Jk's 3D Farm) (каталог в стиле Mobbin), выложенная на GitHub Pages.
На GitHub Pages нет PHP, поэтому заявка не уходит в админку: текст заказа копируется, и открывается Telegram.

Сама тема для WordPress: [download/jk-create.zip](download/jk-create.zip). Её можно поставить на любой хостинг с WordPress, тогда заработают админка наборов и заявки на почту.
